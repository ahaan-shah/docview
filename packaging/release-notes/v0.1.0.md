The first docview release: a small, fast PDF viewer for Linux that also opens web pages, with every action one key away and your pywal colours followed live.

## New

- **PDFs drawn sharp and fast.** Pages render in tiles on a background thread, crisp on HiDPI screens, with continuous or single-page scrolling, two-page spreads, fit width / fit page and any zoom with `Ctrl` + wheel or a pinch.
- **Search and highlight without the mouse.** `Ctrl F` searches the whole document; `Ctrl H` highlights the selection or the current match. Highlights are flat marker strokes saved into the PDF, so other viewers see them; right-click the highlight button to pick a colour.
- **Web pages open too.** HTML files open in a WebKit view with their own top bar: back and forward, zoom, night mode, find, reload and open in your browser. WebKit loads only when a page is opened, so reading PDFs never pays for it. Needs WebKitGTK 6 (`webkitgtk-6.0` on Arch).
- **Every action in one place.** Top-bar buttons, keyboard shortcuts and the command palette (`Ctrl P`) all run the same commands; `Ctrl K` shows every shortcut, and any key can be rebound in `~/.config/docview/config.toml`.
- **Your colours.** System (pywal, or your desktop's light / dark setting), light and dark modes, plus a night mode that recolours pages. The palette updates the moment your wallpaper changes.
- **Light on memory.** About 60 MB with a 1,300-page book open, no CPU while idle, and software rendering that never wakes a discrete GPU.
- **Remembers your place** in every document, reloads a PDF when it changes on disk (handy with LaTeX), and fits any window size: toolbar groups hide instead of being cut off.
- **One-line install** for any Linux distribution, plus `.deb` and `.rpm` packages for x86-64 and ARM64.
