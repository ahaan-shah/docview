Smooth web pages: HTML files now scroll as smoothly as PDFs.

## Fixed

- **Web pages scroll smoothly.** WebKit now composites and scrolls pages on the integrated GPU, on its own scrolling thread, instead of repainting the page on the CPU for every scroll step. Only Mesa's driver is used, so a sleeping NVIDIA GPU stays asleep. While a page is open this costs about 50 MB more in total; PDFs are unchanged and never load the GL driver. With `gpu = false` web pages are still drawn on the CPU.
- **GPU drawing works with Mesa 26.3.** GTK 4.24 could not set up OpenGL at all with Mesa 26.3 ("No EGL configuration available"); docview now works around it.
