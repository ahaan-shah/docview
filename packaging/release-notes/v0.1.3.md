Smooth scrolling: PDFs and web pages now scroll at your screen's full refresh rate, even on HiDPI and 120 Hz displays.

## Changed

- **Smooth scrolling and zooming.** docview now draws with Vulkan on the integrated GPU instead of in software, which could not keep up with a 2x-scaled 120 Hz screen. The NVIDIA driver is never loaded, so a sleeping discrete GPU on a hybrid laptop stays asleep. Without a usable Vulkan driver docview falls back to software rendering by itself.
- **New `gpu` setting.** `gpu = false` under `[app]` in `~/.config/docview/config.toml` goes back to software rendering, which uses about 60–80 MB less graphics memory but scrolls less smoothly.
- **Less work per frame.** Pages that are fully rendered no longer get a background and a low-resolution preview painted underneath them.
